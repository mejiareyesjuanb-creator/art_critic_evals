What the numbers mean
Pass rate
The share of case runs the grader passed. Each case runs several times, so 8 cases at 3 runs each give 24 case runs.
Grade
A band on the pass rate: Strong from 90%, Good from 70%, Weak from 40%, otherwise Failing.
95% interval
The range the true pass rate likely sits in, given how few runs there are (a Wilson interval). When two runs' intervals overlap, their difference could be chance.
Cases solid
Cases whose every run passed.
Dev and holdout
Dev cases are the ones the prompt is tuned against. Holdout cases are never used for tuning, so their pass rate shows whether a prompt change helps on artworks it wasn't tuned for. With only a few holdout cases, treat their rate as rough.
Test set
A short fingerprint of the test cases. It changes whenever a case is edited, added or removed, and runs on different test sets measure different things.
Skipped cases
The image and photograph cases need an image attached, so they don't run yet.
